# 🔥 ഡീൽ ധമാക്ക (Deal Dhamaka KSA) — Amazon.sa Affiliate Aggregator (SAR)

സൗദി അറേബ്യയിലെ **Amazon.sa** ഡീലുകൾ **Saudi Riyal (`SAR`)** ഫോർമാറ്റിൽ പ്രദർശിപ്പിക്കുന്നതിനായി തയ്യാറാക്കിയ വെബ്സൈറ്റ് പ്രോജക്റ്റ് ആണിത്. **GitHub Pages** അല്ലെങ്കിൽ **Vercel**-ൽ നേരിട്ട് ഹോസ്റ്റ് ചെയ്യാം.

## ✨ പ്രധാന സവിശേഷതകൾ:
- **Currency Format:** എല്ലാ വിലകളും സേവിംഗ്സും **`SAR`** ഫോർമാറ്റിലാണ് (ഉദാഹരണത്തിന്: `SAR 3,199`, `MRP SAR 5,399`).
- **Amazon Saudi Arabia (`amazon.sa`):** എല്ലാ ഡീൽ ലിങ്കുകളും ഡിസ്ക്ലോഷറുകളും `amazon.sa`-ലേക്ക് മാറ്റിയിട്ടുണ്ട്.
- **Private Admin CMS:** പൊതുജനങ്ങൾ (Public Visitors) വെബ്സൈറ്റ് സന്ദർശിക്കുമ്പോൾ **CMS ബട്ടണോ**, **Add New Deal ബട്ടണോ** കാണാൻ സാധിക്കില്ല.

## 🔐 അഡ്മിൻ ആയി ലോഗിൻ ചെയ്യാനുള്ള 3 വഴികൾ:
1. **URL വഴി:** നിങ്ങളുടെ വെബ്സൈറ്റ് അഡ്രസ്സിന്റെ അവസാനം `#admin` എന്ന് ചേർക്കുക (ഉദാഹരണത്തിന്: `https://your-site.vercel.app/#admin`).
2. **കീബോർഡ് ഷോർട്ട്കട്ട്:** വെബ്സൈറ്റ് തുറന്ന ശേഷം കീബോർഡിൽ **`Ctrl + Shift + A`** (Mac-ൽ `Cmd + Shift + A`) അമർത്തുക.
3. **സീക്രട്ട് ഫൂട്ടർ ഐക്കൺ:** വെബ്സൈറ്റിന്റെ ഏറ്റവും താഴെ വലതുവശത്തുള്ള ചെറിയ **🔒** ഐക്കണിൽ ക്ലിക്ക് ചെയ്യുക.

- **Default Admin Password:** `admin@123`

1. ഈ സിപ്പ് ഫയലിലുള്ള `index.html`, `vercel.json` എന്നിവ നിങ്ങളുടെ GitHub Repository-യിലേക്ക് അപ്‌ലോഡ് ചെയ്യുക.
